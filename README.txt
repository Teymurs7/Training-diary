ДНЕВНИК ТРЕНИРОВОК — PWA

В комплекте: index.html, manifest.webmanifest, sw.js и иконки.

ВАЖНО: для установки PWA нужен HTTPS-хостинг (или localhost для теста). Само открытие index.html из файлового менеджера не устанавливает PWA и не включает Service Worker.

Публикация: загрузите ВСЕ файлы и папку icons на HTTPS-хостинг, сохранив структуру. Подойдут GitHub Pages, Netlify или Cloudflare Pages. Затем откройте HTTPS-адрес в Chrome на Android → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

Данные дневника сохраняются в localStorage браузера на устройстве. Не очищайте данные сайта без предварительного экспорта JSON из приложения. Для переноса между устройствами используйте экспорт/импорт JSON.
